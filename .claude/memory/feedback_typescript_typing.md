---
name: TypeScript Duck Typing Preference
description: Prefer structural typing (duck typing) over nominal typing in TypeScript
type: feedback
---

Prefer duck typing (structural typing) for TypeScript code.

**Why:** Structural typing is more flexible and aligns with TypeScript's philosophy of optional type strictness.

**How to apply:** When writing or suggesting TypeScript code, favor interfaces/types that are satisfied by structure rather than explicit inheritance or type declarations. Avoid nominal typing patterns where possible.
